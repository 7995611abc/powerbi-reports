# Publishing checklist

## GitHub
1. Sign in to GitHub and create a **public** repository named `uk-retail-sales-analytics` (or similar).
2. Upload the **contents** of this folder, preserving the subfolders, or use Git from your computer.
3. Confirm README renders on the repository homepage; verify all images and notebook paths.
4. Add the `.pbix` and `.twbx` exports from your actual applications if you want reviewers to open native dashboards.
5. Replace placeholder owner details and add real dashboard URLs.
6. Review the repo to ensure no credentials or private customer data were included.

## LinkedIn
1. Add the project in your profile's Projects section, using `career/LINKEDIN_AND_CV.md`.
2. Add the GitHub URL as linked media and optionally feature it on the profile.
3. Publish the LinkedIn post after verifying your links.

## CV
1. Copy the four project bullets into a **Projects** section.
2. Link the GitHub repository in the project title or next to it.
3. Mention synthetic data openly if the project is discussed in an interview.

## Interview explanation
Business goal → source & cleaning → tools & calculations → verified results → two findings → limitations → what you would investigate next.

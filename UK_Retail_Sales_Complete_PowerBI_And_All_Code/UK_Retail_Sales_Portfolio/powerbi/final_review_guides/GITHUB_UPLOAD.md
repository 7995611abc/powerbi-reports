# GitHub publishing steps

1. Add actual `.pbix` and screenshots before publishing.
2. Create public repository `uk-retail-sales-powerbi-dashboard` at https://github.com/new.
3. Upload contents of this kit (not the ZIP) to the repository.
4. Confirm README preview renders all three screenshot links.
5. Verify the repository includes source CSV, DAX, calendar table and an unambiguous synthetic-data statement.
6. Check `.pbix` file size and GitHub upload limits before uploading; use Git LFS if appropriate.
7. Link your repository on your CV and LinkedIn after confirming all artifacts are authentic.
8. Optional: Publish to web only if you understand this exposes report and underlying model data publicly; publishing depends on Power BI account and tenant policies.
